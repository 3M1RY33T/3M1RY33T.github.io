My personal portfolio and technical blog. This website is where I present my software projects, write about what I am building, and keep a public record of technical updates, releases, experiments, and engineering notes.

## What This Site Is

The site is a portfolio, blog, and lightweight product journal. It is focused on the kinds of work I do most often: mobile development, backend tooling, static-site infrastructure, developer tools, and practical software engineering.

The homepage introduces my work, featured projects, technical skills, recent posts, and contact information. The blog is where I publish project updates, release notes, implementation details, and notes from ongoing work.

## What I Share Here

- Project releases and changelogs.
- Technical notes from things I am building or improving.
- Mobile, web, backend, and tooling experiments.
- Updates about my open-source projects.
- Practical writeups about deployment, infrastructure, and product polish.
- Portfolio updates as the site itself evolves.

## Website Features

- Responsive portfolio homepage with project cards and skill icons.
- Categorized skills section covering languages, mobile development, web development, backend/systems, databases, and cloud/dev services.
- Featured recent posts on the homepage.
- Social-feed style blog page with expandable posts.
- Wider desktop blog layout that uses available screen space while keeping mobile compact.
- Two-column desktop post previews when a post includes media.
- Single-image and image-slider previews inside the blog feed.
- Swipe/drag support for image sliders on mobile and tablet viewports.
- Individual post pages for longer articles and release notes.
- Post likes and moderated comments powered by [`urthreads`](https://github.com/3M1RY33T/urthreads).
- Static admin dashboard for managing engagement data.
- Compact, themed code blocks for technical posts.
- Theme-aware favicon and visual polish across the blog feed.

## Featured Areas

**Projects**

The project section highlights software I have built or actively maintain, including tooling, services, mobile apps, and open-source work.

**Blog**

The blog is used for release posts, technical updates, infrastructure notes, and project retrospectives. Recent posts include updates about Tensor Serve and the integration of urthreads into this portfolio.

**Skills**

The skills section reflects the technologies I work with across mobile development, backend systems, web development, databases, and cloud/dev tooling.

**Engagement**

The blog supports likes and moderated comments without requiring visitor accounts. That system is powered by urthreads, my self-hosted static-site engagement service for Cloudflare Workers and D1.
